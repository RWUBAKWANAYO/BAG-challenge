# BAG-Challenge
<h3>BAG Front-End Coding Challenge.</h3>

BAG Front-End Coding Challenge, is frontend project which can display informations of all countries in the world such as country name,population, capital city,currency,etc... 
And this project provide ability to search search country of your choice using keyword or filter country by content, for purpose of get country or contries of your choice without step through all countries.
You can also get other features such change theme (dark mode/light mode) of  web page for content readibility purpose

## Installation 

Dowload or Clone repository [git@github.com:key-joshua/BAG-Challenge.git] to get BAG Front-End Coding Challenge on your text editor.

* With http

  ```bash
  git clone https://github.com/key-joshua/BAG-Challenge.git
  ```
  
 * With ssh

    ```bash
    git clone git@github.com:key-joshua/BAG-Challenge.git
    ```
    
Switch into development branch by running git checkout dev
```bash
git checkout dev
```

Run the npm cache clean --force &npm install by installing required libraries.
```bash
npm cache clean --force
npm install
```
## Usage

After installation successfully - should run npm run client or npm run start by starting the project.
```bash
npm run start
```
Since you run above command you ready to test the application on localhost:3000 or http://xxx.xxx.xx.x:3000  .
